# Branding

`assets/logo.png` is the original raster logo generated with the built-in image
renderer. `assets/logo.svg` is a compact vector companion for small sizes and
favicons. The documentation uses the SVG for crisp display.

Generation prompt: Create a finished logo for semrush-cli, an independent SEO
research tool for the terminal. Black background. Warm orange and white. An
angular terminal chevron integrated with ascending analytics bars. Flat,
vector-like shapes. No official Semrush flame, gradients, shadows, text or frame.

The logo does not imply affiliation with Semrush.
