`semrush-cli` is implemented in TypeScript using the Effect library, with a background daemon for session persistence.

## Prerequisites

Building from source requires:
- Node.js 22 or newer
- Go 1.23 or newer (required to compile the local Galleton daemon from source; end users installing from npm do not need Go)
- Standard Unix utilities (`tar`, `patch`)

## Setup and build

Clone the repository and install dependencies:

```sh
git clone https://github.com/Microck/semrush-cli
cd semrush-cli
npm ci
npm run check
```

To build the documentation site locally:

```sh
npm --prefix docs-site ci
npm --prefix docs-site run build
```

## Architecture

The CLI commands and stdio MCP server share a single service layer and operation catalog. For details on architectural boundaries, session handling, and credential isolation, see [docs/architecture.md](https://github.com/Microck/semrush-cli/blob/main/docs/architecture.md) in the project repository.
