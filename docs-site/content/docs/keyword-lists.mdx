title: Keyword lists and Strategy Builder
description: Manage Keyword Strategy Builder baskets, domain strategies, keyword clustering, and exports.

Semrush provides two Keyword Strategy Builder workflows: domain-based strategies and seed-based keyword baskets.

## Identifier requirements

- **Domain strategy ID (`strategy_id`)**: A numeric integer returned by `domain-strategy-create`.
- **Basket ID (`basket_id`) and Owner ID (`owner_id`)**: Numeric integers returned by `keyword-lists`. Both are required when targeting a seed-based list.
- **Saved Keywords list ID (`list_id`)**: A decimal string used by the [Saved Keywords](/docs/saved-keywords) commands.

## Domain-based strategies

Generate high-level content strategies around an existing root domain:

```sh
semrush domain-strategies --limit 20 --offset 0 --json
semrush domain-strategy-summary --json
semrush domain-strategy-create --domain example.com --database us --dry-run
semrush domain-strategy-create --domain example.com --database us --confirm --json
```

Creation initiates strategy generation and returns `data.id`. Check completion status before inspecting pages:

```sh
semrush domain-strategy-status --strategy-ids '[123]' --json
semrush domain-strategy-get --strategy-id 123 --json
semrush domain-strategy-rename --strategy-id 123 --name 'Q4 Strategy' --confirm
semrush domain-strategy-delete --strategy-ids '[123]' --confirm
```

### Inspecting domain page opportunities

Once generation finishes, inspect page recommendations by preset (`all`, `improve`, or `create`):

```sh
semrush domain-strategy-presets --strategy-id 123 --json
semrush domain-strategy-pages --strategy-id 123 --preset improve --limit 20 --offset 0 --json
semrush domain-strategy-pages-summary --strategy-id 123 --preset improve --json
semrush domain-strategy-page --page-id 456 --json
semrush domain-strategy-existing-keywords --page-id 456 --json
semrush domain-strategy-recommended-keywords --page-id 456 --json
```

Filter opportunities by keyword volume and intent using `--volume-min`, `--volume-max`, `--difficulty-min`, and `--primary-intents '["commercial","transactional"]'`.

Export the strategy to disk:

```sh
semrush domain-strategy-export --strategy-id 123 --format csv --output strategy.csv
```

The CLI verifies that `strategy.csv` does not already exist before initiating download.

## Seed-based lists (baskets)

Create and manage custom keyword baskets:

```sh
semrush keyword-list-limits --json
semrush keyword-lists --page 1 --page-size 50 --json
semrush keyword-list-create --name 'TypeScript Tools' --confirm --json
semrush keyword-list-get --basket-id 456 --owner-id 123 --json
semrush keyword-list-rename --basket-id 456 --owner-id 123 --name 'Dev Tools' --confirm
semrush keyword-list-delete --basket-id 456 --confirm
```

### Importing and managing keywords

```sh
semrush keyword-list-import --basket-id 456 --owner-id 123 \
  --keywords '["typescript framework","deno runtime"]' --database us --confirm
semrush keyword-list-keywords --basket-id 456 --owner-id 123 --json
semrush keyword-list-summary --basket-id 456 --owner-id 123 --json
semrush keyword-list-add-tags --basket-id 456 --owner-id 123 \
  --keywords '["deno runtime"]' --tags '["runtime"]' --confirm
semrush keyword-list-update-metrics --basket-id 456 --owner-id 123 \
  --keywords '["typescript framework"]' --confirm
```

To delete phrases from a list:

```sh
semrush keyword-list-delete-keywords --basket-id 456 --owner-id 123 \
  --keywords '["deno runtime"]' --confirm --json
```

Copy `.data.UndoID` from the deletion result to restore those phrases:

```sh
semrush keyword-list-undo-delete --undo-id 'undo-id-placeholder' --confirm
```

### Clustering keyword lists

Group phrases into semantically coherent topic clusters:

```sh
semrush keyword-list-cluster --basket-id 456 --owner-id 123 --confirm --json
semrush keyword-list-cluster-status --basket-id 456 --owner-id 123 --json
semrush keyword-list-clusters --basket-id 456 --owner-id 123 --json
semrush keyword-list-cluster-keywords --basket-id 456 --owner-id 123 --cluster-id 789 --json
```

### Generating a strategy from seed phrases

Generate a strategy with related keywords from your seed phrases:

```sh
semrush keyword-strategy-create --name 'TypeScript Strategy' \
  --seed-keywords '["typescript framework","javascript framework"]' --confirm --json
```

Use the returned `data.BasketID` and its `Owner.ID` from `keyword-lists` to read the forecast and progress:

```sh
semrush keyword-list-cluster-forecast --basket-id 456 --owner-id 123 --json
semrush keyword-list-cluster-status --basket-id 456 --owner-id 123 --json
```

Creation starts generation and uses your account allowance. A regular imported list can return `not found` for the forecast read.

### Exporting lists and mind maps

Export keywords or visual cluster diagrams:

```sh
semrush keyword-list-export --basket-id 456 --owner-id 123 --format csv --output list.csv
semrush keyword-list-export-mindmap --basket-id 456 --owner-id 123 --format png --output mindmap.png
```
