First complete `semrush setup` and authentication. Add this to your MCP client's configuration:

```json
{
  "mcpServers": {
    "semrush": {
      "command": "semrush",
      "args": ["mcp"]
    }
  }
}
```

If your client cannot find global npm executables, use the absolute path printed
by `command -v semrush` on macOS/Linux or `Get-Command semrush` in PowerShell.
Alternatively, configure:

```json
{
  "mcpServers": {
    "semrush": {
      "command": "npx",
      "args": ["-y", "semrush-cli@0.12.0", "mcp"]
    }
  }
}
```

Tool names use underscores, such as `domain_overview`, `keyword_magic` and `backlink_gap`. Their inputs use the same schema keys as the CLI, with underscores instead of hyphens.

```json
{
  "name": "keyword_magic",
  "arguments": {
    "keyword": "email marketing",
    "database": "us",
    "page": 2,
    "page_size": 20
  }
}
```

The server sends only MCP protocol messages to stdout. The 136 read tools have `readOnlyHint:true`. The 59 write tools have
`readOnlyHint:false` and require `confirm:true`. Delete and leave also have
`destructiveHint:true`. Use `dry_run:true` to validate and inspect a write without
connecting to Semrush. A write without confirmation fails before authentication.
Login, daemon management, arbitrary URLs and JavaScript execution are not exposed. Report calls can still consume normal account allowances.

Tool errors have `isError: true`. Reimport an expired session and restart or reconnect the MCP process. Each process owns and cleans up its transient browser.


## Read an export

Call `keyword_list_export`, `keyword_list_export_pages`,
`keyword_list_export_keywords` or `keyword_list_export_clusters` with
`basket_id` and `owner_id` to export a seed-based basket. Each uses the
selection documented in [keyword lists](/docs/keyword-lists#read-seed-based-pages-and-clusters).

Call `domain_strategy_export` with a numeric `strategy_id` and a basename
`filename`, or `saved_keywords_export` with a decimal-string `list_id`. Both
support `csv`, `csv_semicolon` and `xlsx`. Domain export includes the whole
filtered strategy; it does not accept a page preset. Alternatively, call
`audit_export_pages`, `audit_export_issues` or `audit_export_issue` with a
`snapshot_id` and optional `format:"xlsx"`. Tool inputs do not include the CLI's
local `output` path. The result includes an `artifact` with `uri`, `filename`,
`mime_type` and `size_bytes`.

Use MCP `resources/read` with that URI. Each response contains up to 65536 bytes
as base64. For larger files, request `?offset=65536&limit=65536` and continue
until the total matches `size_bytes`. Decode each chunk and concatenate the
bytes, including for XLSX files. The maximum chunk is 1048576 bytes.

`resources/list` lists downloads created by this MCP process. Files live in a
private temporary directory and disappear when the process exits. URIs from a
previous process cannot be reopened. Download tools are reads, but account
export permissions and quotas still apply.
