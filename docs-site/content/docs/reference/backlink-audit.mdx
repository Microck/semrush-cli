```sh
semrush backlink-audit-target-pages --help
```

MCP tool: `backlink_audit_target_pages`.

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `--audit-id` | integer |  | Required. Backlink Audit userDomainId returned by backlink-audit-info. |
| `--query` | string | `""` |  |
| `--query-mode` | string / null | `null` |  |
| `--by-domain` | boolean | `true` | Count backlinks grouped by referring domain; false counts individual backlinks. |
| `--target-error` | boolean / null | `null` |  |
| `--labels` | array | `[]` |  |
| `--is-new` | boolean | `false` |  |
| `--sort-field` | string | `"active"` |  Values: `"active"`, `"new"`, `"broken"`, `"lost"`, `"ga_users"`, `"ga_users_perc"`, `"ga_new_users"`, `"ga_new_users_perc"`. |
| `--descending` | boolean | `true` |  |
| `--page` | integer | `0` |  |
| `--page-size` | integer | `50` |  |

## backlink-audit-import

```sh
semrush backlink-audit-import --help
```

MCP tool: `backlink_audit_import`.

Use `--confirm` to send the change or `--dry-run` to preview it.

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `--contents-file` | file or stdin |  | Required. Native CSV containing source URLs in its first column. Sent unchanged; files with no importable URLs are refused before commit. |
| `--filename` | string | `"semrush-backlinks.csv"` | CSV upload filename ending in .csv. |
| `--confirm` | boolean | `false` | Confirm this account mutation. |
| `--dry-run` | boolean | `false` | Print the request without sending it. |
| `--audit-id` | integer |  | Required. Backlink Audit userDomainId returned by backlink-audit-info. |
