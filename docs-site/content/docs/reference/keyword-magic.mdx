## keyword-magic

Paginated Keyword Magic research with filters and sorting.

```sh
semrush keyword-magic --help
```

MCP tool: `keyword_magic`.

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `--keyword` | string |  | Required.  |
| `--database` | string | `"us"` |  |
| `--questions-only` | boolean | `false` |  |
| `--mode` | integer | `4` | Web Keyword Magic matching mode |
| `--currency` | string | `"USD"` |  |
| `--sort-field` | string |  | Native table sort; defaults to similarity_score for topics or volume for word groups. |
| `--descending` | boolean | `true` |  |
| `--filters` | object |  | Keyword Magic web filter object |
| `--groups` | array | `[]` |  |
| `--page` | integer | `1` |  |
| `--page-size` | integer | `100` |  |
| `--domain` | string |  | Bare root domain for already prepared native personalized data. Does not start preparation. |
| `--group-by` | string | `"topics"` | Native topic grouping or classic word grouping. Values: `"topics"`, `"words"`. |
| `--groups-sort-field` | string |  | Sort word groups by keyword count or volume. Only with group_by words. Values: `"count"`, `"volume"`. |
| `--groups-descending` | boolean |  | Word-group sort direction; defaults to true. Only with group_by words. |
