## audit-web-vitals-settings-set

Replace the complete Core Web Vitals URL list for the next audit. Requires one to ten URLs; the native API rejects empty lists. Does not launch a crawl; partial acceptance requires inspecting the saved list before another write.

```sh
semrush audit-web-vitals-settings-set --help
```

MCP tool: `audit_web_vitals_settings_set`.

Use `--confirm` to send the change or `--dry-run` to preview it.

| `--campaign-id` | integer |  | Required. SEO project/campaign ID from project-enable-seo, not the folder ID. |
| `--urls` | array |  | Required. One to ten unique absolute HTTP(S) URLs. Replaces the full saved selection. |
| `--confirm` | boolean | `false` |  |
| `--dry-run` | boolean | `false` |  |
