## Verification

All 48 original research request mappings have differential tests against the
Python reference. Stateful project lifecycle tests use real Chromium, a private
Galleton daemon and an HTTP fixture. Live account checks verified project
creation, readback, renaming, tag replacement, pinning, toolkit status and metrics.
The disposable verification project was deleted and its absence checked.
Existing account projects were not modified.

The request sources are Semrush's current
[project dashboard client](https://static.semrush.com/crossroad/release/app-bootstrap-b747fd8495662359751f.min.js)
and its
[project selector module](https://static.semrush.com/crossroad/release/774-b153c46fe3f656452904.min.js).
Creation was also captured directly from the web form with submission blocked,
before the CLI's live lifecycle verification. Internal endpoints can change.

Live verification enabled a disposable SEO project, saved manual Site Audit
settings with email disabled, and launched a crawl capped at 10 pages on
example.com. Existing account projects were not changed. Shared-project leave retains request-contract coverage without live execution.
Automatic SEO setup created a target and a completed audit. A later live pass verified metric refresh, clustering and structured
strategy generation on disposable keyword lists.


The current verification pass also checked Position Tracking creation and
rankings on a disposable example.com target. Keyword, tag and competitor writes
passed readback checks, including deletion and clearing competitors. Site Audit
stop controls passed on an isolated slow-crawl fixture; finalize saved a new
snapshot after processing. Page, issue-summary and individual-issue exports
passed as both CSV and XLSX, with MCP resource reads.

The current account has no prompt-tracking allowance and the Advertising Toolkit
UI displays a paywall. A full paid-position request returned an access denial.
Those products are not verified as working, and no subscription was purchased.


All 90 reads in version 0.6.0 passed live calls on 2026-10-15. This includes
empty-result reports and account capability reads; it does not imply every
paid toolkit is unlocked. Clustering forecast used a structured strategy,
and audit page details used a fresh page ID from the current crawl.

The Saved Keywords pass added 28 operations, all verified through live calls.
Thirteen new writes passed state readbacks on two disposable collections.
CSV, semicolon CSV and XLSX exports passed file checks, including CLI saving
and overwrite refusal. Cleanup verified both collection IDs and the disposable
audit project were absent; unrelated account data was preserved.

The domain-strategy pass verified all 17 new operations on a disposable strategy
with 134 page opportunities. Pagination, filters, keyword deletion and all three
export formats passed. Cleanup checked the strategy ID was absent. The shared
download change also passed all six Site Audit and three Saved Keywords export
regressions. Across these passes, all 118 reads and 46 of 47 writes have live
execution evidence.
Shared-project leave remains unverified.


The seed-based pass verified 15 additional operations. One generated strategy
contained 10 topics and 243 pages. Favorites and removal, selected-cluster metric
refresh and cluster deletion passed readback checks. All four export selections
passed CSV, semicolon CSV and XLSX checks. Full exports contained 1,979 keyword
rows; selected-cluster and selected-phrase exports contained only their selected
rows. The owned strategy was deleted and its ID checked absent. Across the
versioned passes, all 129 reads and 50 of 51 writes have live execution evidence.
Shared-project leave still has contract coverage only.


The settings and transfer pass verified five additional writes. Partial tracking
edits preserved omitted fields and the target identity. Business-name clearing
passed; empty brand-list clearing did not, and the input schema now rejects it.
All four selected transfer operations passed source and destination readbacks,
including the seven expected destination rows. Across versioned passes, all
129 reads and 55 of 56 writes have live execution evidence. Shared-project leave
still has contract coverage only.
