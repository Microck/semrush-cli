title: Workflow coverage
description: Overview of supported web workflows, capabilities, and unsupported features.
---

`semrush-cli` covers the core research, project management, and audit workflows available in the Semrush web interface. Operations use your existing web account permissions and allowances.

## Supported workflows and limitations

| Feature area | Supported CLI and MCP capabilities | Unsupported web features |
| --- | --- | --- |
| Keyword Overview | Search volume, difficulty, intent, trends, SERPs, country databases, local SERPs, domain personalization, bulk analysis, native CSV/XLSX downloads, and Keyword Overview PDFs through My Reports. | Chart image downloads and full AI topic exports. |
| Keyword Magic | Word and topic grouping, questions filter, pagination, sorting, and summary metrics. | Direct selected-row file downloads. |
| Organic Research | Domain rankings, top pages, subdomains, competitor identification, daily/monthly position changes, and historical trends. | Direct CSV/XLSX and Overview PDF downloads, interactive visual charts. |
| Competitor Gap | Organic keyword gap and backlink gap comparisons across two to five domains. | Interactive Venn diagrams and outreach CRM integrations. |
| Backlink Analytics | Referring domains, backlinks, anchor texts, indexed pages, authority scores, and historical link trends. | Direct file exports through this endpoint. |
| Backlink Audit | Campaign setup, scope replacement, toxicity reports, review lists, target-page labels, comments, CSV imports, reruns, and native CSV/disavow exports. | Connecting Google services, sending removal outreach, and submitting disavow files to Google. |
| AI Visibility | Domain visibility, country breakdowns, citation sources, and account access limits. | Creating and managing prompt-tracking campaigns. |
| Projects | Creation, domain attachment, folder management, tags, pinning, dashboard toolkit metrics, sharing, viewer/editor permissions and access revocation. | Organization-wide seats and account administration. |
| Keyword Strategy Builder | Domain strategy generation, page opportunity inspection, basket creation, keyword clustering, and mind map image downloads. | Direct content generation workflows. |
| Saved Keywords | Collection management, FilterQL queries, tags, workflow milestone labels, and CSV/XLSX exports. | Automated content generation. |
| Site Audit | Settings configuration, HTTP Basic Auth, Web Bot Auth, uploaded crawl lists, crawl start/finalize/abort, JS Impact analysis, and CSV/XLSX/ZIP exports. | Google Analytics OAuth linking within the CLI. |
| On Page SEO Checker | Landing page and keyword configuration, optimization ideas, SERP details, and single-page runs. | Connected Google Search Console workflows and standalone semantic density metrics. |
| Core Web Vitals | LCP, TBT, and CLS scores, dated page-status counts, Lighthouse recommendations, and monitored URL selection replacement. | Clearing the monitored URL selection (API requires 1 to 10 URLs), native spreadsheet exports, and PDF reports. |
| Position Tracking | Target creation, daily ranking reads, competitor tracking, alert triggers, ranking distribution, and competitor discovery. | Advanced crawl schedules and PDF reports. |
| My Reports | System and custom templates, reusable report creation, template sharing and restoration, allowances, saved report pagination, creation, complete document editing, cloning, PDF generation, task listing, PDF downloads, sharing, viewer/editor permissions, access revocation and permanent deletion. | Reporting tier upgrades and connected-service setup. |
| Chart Notes | Note listing, creation, updates, deletion, chart visibility controls, and full CSV exports. | Rendering notes on visual charts. |
